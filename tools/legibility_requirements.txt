#
# Every version is pinned to the one the statistics in tools/legibility_reference.json
# were parsed with. A different parser draws different arcs and tags, and every ratio
# would then compare two instruments rather than two texts. Raising a pin means
# re-measuring the baseline with the new parser in the same change.
#
# The CPU build of torch: the check parses a few thousand words, and the CUDA build
# would download several gigabytes of vendor libraries a runner cannot use.
